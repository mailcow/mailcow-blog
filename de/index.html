Von Microsoft 365 Zu Mailcow: Postfächer Mit Den Neuen Sync-Jobs Umziehen

The Infrastructure Company GmbH veröffentlicht an 24.11.2026 enthalten in Anleitungen

Moohoo zusammen!

Viele von euch kommen zu mailcow, weil sie ihre E-Mails nicht länger in Microsoft 365 haben wollen. Der größte Brocken beim Umzug sind fast immer die Postfächer. Mit Update 2026-11 haben wir die Sync-Jobs deshalb komplett überarbeitet: Sie melden sich jetzt per OAuth2 direkt bei Microsoft 365 an und laufen auf Wunsch parallel.

In diesem Beitrag zeigen wir Schritt für Schritt, wie ihr eure Postfächer aus Microsoft 365 nach mailcow übernehmt.

🎄🐮 Moozember 2025 | Ein Weiteres Bugfix-Update - Revision A

The Infrastructure Company GmbH veröffentlicht an 09.12.2025 enthalten in Updates
Warnung

Wenn ihr Docker Compose v5 verwendet, stellt bitte sicher, dass ihr zuerst diese kleinen Korrekturen anwendet, um zu verhindern, dass das update.sh-Skript fehlschlägt:

1
2

git fetch
git checkout origin/master update.sh

Ohne dies wird euch das Update-Skript mitteilen, dass eure Docker Compose-Version nicht unterstützt wird, selbst wenn ihr v5 verwendet.

Dies liegt an einem kleinen Tippfehler in der Versionsprüfung, der zwar behoben wurde, aber möglicherweise manuell angewendet werden muss, wenn ihr bereits Docker Compose v5 nutzt.
